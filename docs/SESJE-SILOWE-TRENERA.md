# Sesje siłowe trenera – surowe notatki (źródło dla biblioteki)

Zapis: `1)` = blok, `a) b) c)` = ćwiczenia w parze/trójce w obrębie bloku (np. siła + plyo). `SxP` = serie x powtórzenia. `/leg` `/side` `/arm` = na stronę. `(4-1-x)` = tempo. `%1RM` = procent maksimum.

Skróty: iso = izometria, SL = jednonóż, HT = hip thrust, tbdl = trap bar deadlift, MB = piłka lekarska, SA = jednorącz, BB = sztanga, CMJ = skok z wymachem, plyo = pliometria, Str L = straight leg, add = przywodziciele, abd = odwodziciele.

## A. Szkic ogólny (sesja „na luzie")
1) iso push + skoki (2 serie)
2) tbdl + plyo + skoki z asystą gumy (maks 3 powt.)
3) góra do 5 powt., 3 serie (push/pull)
4) akcesoria wedle uznania

## B. Day 1 (16 IX 2024)
Str L SL HT iso hold 3x8/side
1) a) Hang Power clean 4x2 · b) Pogo jumps 3x6
2) a) Quarter box squat 4x2 · b) Drop box jump 4x3
3) a) MB shotput 3x5/side · b) SL banded HT 3x5/leg
4) a) SA plyo row 3x5/arm · b) Rebound back ext 3x6
5) a) High sideplank abd 3x8/leg · b) Standing banded hip flexion 3x8/leg · c) Kopenhagen add str L 3x6/side

## Obserwacje
- D i E to ten sam „Day 1" w dwóch fazach: mniej serii i powt. przy 90–95% 1RM vs więcej przy 80–85%. Progresja = zmiana fazy, nie tylko dodanie kilogramów.
- Sesja zaczyna się od izometrii/pliometrii (potencjacja), potem ciężka siła sparowana ze skokiem (kontrast), na końcu akcesoria.
