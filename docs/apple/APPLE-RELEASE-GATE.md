# Apple release gate — BallWise

Aktualną bramką jest [wspólna lista wydania](../RELEASE-CHECKLIST.md), sekcja
iOS, App Store i płatności, wraz z [macierzą QA](../QA-MATRIX.md).
Nie utrzymujemy drugiej kopii tych samych checkboxów.

StoreKit, paywall, przywracanie zakupów i zarządzanie subskrypcją pozostają
[propozycją](IAP-SUBSCRIPTION-SPEC.md). Są warunkiem przyszłego płatnego wydania,
nie funkcjami potwierdzonymi w bieżącym kodzie. Sam build mobilny nie potwierdza
podpisania archiwum ani gotowości App Review.
