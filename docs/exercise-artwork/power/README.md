# BallWise — grafiki ćwiczeń mocy

11 aktywnych grafik PNG w [public/power/small](../../../public/power/small)
ma rozmiar 768 × 512 px. Trzy fazy ruchu biegną od lewej do prawej; zielona
ilustracja liniowa na jasnym tle i strzałki pokazują kierunek ruchu.
Nazwa pliku odpowiada kanonicznemu `exerciseId`.

[Manifest](manifest.csv) zawiera kolejność, ID, polską nazwę, ścieżkę względem
tego katalogu oraz opis kierunku ruchu. [Podgląd](../preview/power.jpg) jest
materiałem do przeglądu ilustracji i nie jest zasobem aplikacji.

Zasady obu systemów grafik opisuje [główna instrukcja](../README.md).
