# Siła bez siłowni – drabinki trudności

Zamiast ciężaru: ten sam wzorzec ruchu w coraz trudniejszym wariancie. Szczebel zależy od poziomu (początkujący 0, średni 2, zaawansowany 3), +1 w fazie intensywnej, −1 w rozładowaniu.

- Przysiad: przysiad z masą ciała → wykrok → przysiad bułgarski → jednonóż z asystą → jednonóż
- Biodro/tył uda: glute bridge → jednonóż → martwy ciąg jednonóż → nordic z asystą → nordic curl
- Pchanie: pompki z podwyższeniem → pompki → nogi wyżej → łucznika
- Ciągnięcie: podciąganie poziome → nogi wyżej → łucznika (wymaga drążka lub stabilnego stołu)
- Skoki: pogo → wyskok z przysiadu → bounding → skoki jednonóż

ŹRÓDŁO: standardowe progresje kalisteniczne z wiedzy ogólnej; NIE z konkretnych badań i nie od trenera. Do przeglądu.
Pozycja NIE zmienia siły (decyzja użytkownika).
