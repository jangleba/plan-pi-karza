# BallWise — komplet grafik ćwiczeń

Paczka zawiera łącznie **71 grafik PNG**:

- `strength/small/` — 44 ćwiczenia siłowe
- `plyometric/small/` — 16 ćwiczeń plyometrycznych
- `power/small/` — 11 ćwiczeń mocy

Wszystkie grafiki mają rozmiar 768 × 512 px i przedstawiają kolejne fazy ruchu. Nazwa każdego pliku odpowiada identyfikatorowi `exerciseId` w silniku. Grafiki plyometryczne i mocy zawierają delikatne strzałki kierunku ruchu.

W każdym katalogu kategorii znajduje się `manifest.csv` z nazwami ćwiczeń. Folder `preview/` zawiera zbiorcze podglądy, a `reference/` — zatwierdzony wzorzec postaci.
