# BallWise — grafiki ćwiczeń mocy

- 11 grafik PNG
- rozmiar: 768 × 512 px
- układ: trzy fazy ruchu od lewej do prawej
- styl: minimalistyczna zielona ilustracja liniowa na jasnym tle
- strzałki pokazują główny kierunek ruchu
- nazwa pliku odpowiada polu `exerciseId`

Plik `manifest.csv` zawiera kolejność, identyfikator, polską nazwę i opis kierunku ruchu.
